# Novel-Switch-AI video prompts

将小说片段一键转换为三份可交付的 Markdown 文件：**横屏短剧剧本 → 视频生成分镜方案 → AI 绘图场景提示词**。

三阶段流水线，输出顺序固定：先剧本，再基于剧本出分镜，再基于剧本的场景列表出绘图提示词。每份输出保存为独立的 `.md` 文件，并在回复中完整展示。

## 工作流程总览

```
用户粘贴小说片段
   │
   ▼
阶段一：改编为横屏短剧剧本（16:9，写实风格）
   │       输出：<剧名>_剧本.md
   ▼
阶段二：剧本 → 视频生成方案（按镜头拆分，单镜≤10秒）
   │       输出：<剧名>_视频生成分镜.md
   ▼
阶段三：剧本场景列表 → AI 绘图场景提示词（五部分）
          输出：<剧名>_场景AI绘图提示词.md
```

**重要约定**：三个阶段必须串行执行并共用同一份"世界设定"。阶段二只依据阶段一的剧本拆分镜头，阶段三只依据阶段一的场景列表生成提示词。不要臆造剧本中不存在的角色、地点或事件。文件命名默认用 `<剧名或第X集>_剧本.md`、`<剧名或第X集>_视频生成分镜.md`、`<剧名或第X集>_场景AI绘图提示词.md`。

**优先级规则（处理所有冲突，自上而下）**：
1. 用户的显式指令优先于本 skill 的默认约定。用户若指定了文件路径、文件名、篇幅上限、汇报长度或任何与本 skill 默认写法冲突的要求，一律按用户的来；此时三份文件仍必须完整落盘，回复中可只给路径与摘要。
2. 剧情真实性优先于格式数字。片段内容撑不满 6 场时，按实际内容定场数（可少于 6 场），禁止为凑"6-12 场/集"而臆造事件、人物或转折。
3. 时空连续性优先于凑场数。同一时间同一空间内的一段戏，不因"场数不足"而强行切场景。
4. 三阶段共用同一份"统一设定表"（见阶段一），阶段三必须复用，禁止自行发明新的光线或材质。

## 画风配置（自定义画风）

本 skill 默认输出**写实画风**，但允许用户自定义画风，画风贯穿三个阶段的所有输出。

### 规则

1. **默认画风**：写实（`Photorealistic`）——现实主义电视剧质感（如《漫长的季节》《隐秘的角落》）。
2. **用户指定优先**：用户明确说出画风（如"动漫风""水墨风""3D 渲染""赛博朋克""像素风"）时，用该画风覆盖默认；用户未提及时保持写实，不要自作主张换画风。
3. **画风影响范围（三处必须一致）**：
   - 阶段一：剧本的"角色设定/风格底线"按画风适配（写实＝自然克制表演＋自然光；动漫＝允许夸张表情与明快配色；3D＝强调体积与质感；水彩＝柔化轮廓与低饱和色；其余画风类推）。
   - 阶段二：分镜的画面内容与光线质感描述按画风适配（但"景别/机位/时间轴"等技术参数不变）。
   - 阶段三：场景提示词的**英文画风后缀**按下方画风表替换（默认是 `Photorealistic`）。
4. **预设画风表**（用户说出关键词时替换；表外的画风按用户原话直译成英文画风词，如"蒸汽朋克"→`Steampunk style`）：

| 用户说法（关键词） | 英文画风词（替换 Photorealistic） |
|-------------------|----------------------------------|
| 写实 / 现实 / 真人 / 默认（不指定） | Photorealistic |
| 动漫 / 日漫 / 二次元 / 动画 | Anime style |
| 国漫 / 2D动画 / 卡通 | 2D animation style |
| 3D / 三维渲染 / 皮克斯 | 3D render, Pixar-style |
| 美漫 / 漫画 / 美式 | Comic book style |
| 水彩 / 水墨 / 中国风 | Watercolor / ink-wash painting style |
| 油画 / 古典 | Oil painting style |
| 像素 / 复古游戏 / 8bit | Pixel art |
| 赛博朋克 / 科幻霓虹 | Cyberpunk style |
| 胶片 / 电影感 / 复古胶片 | Cinematic, film grain |

5. **输出时显式声明画风**：每份文件开头标注 `画风：<中文名>（<英文画风词>）`，例如"画风：写实（Photorealistic）"或"画风：动漫（Anime style）"，便于核对三阶段一致。
6. **后缀措辞适配**：除画风词外，后缀中与写实/摄影相关的措辞也按画风适配——`natural or artificial lighting as per context` 在特定画风下改为对应光照描述（如赛博朋克→`neon lighting`、水墨→`soft ambient light`）；`realistic material textures`、`commercial photography style`、`cinematic color grading` 等措辞与动漫/水墨等画风冲突时，替换为与画风一致的措辞或直接删除。默认写实画风下保留全部原措辞。
7. **画风不改变剧情时间与氛围**：画风只改变表现手法，不改变场景的时间/天气/明暗设定——雨夜就是雨夜，即使画风是"明快配色"的动漫也要保持夜景氛围，此时按画风调整调色倾向即可（如动漫夜景→冷暖高对比、赛璐璐式打光；水墨夜景→更深的墨色层次与留白）。

## 阶段一：小说片段 → 横屏短剧剧本

### 角色设定

你是一位现实主义题材的影视编剧，专攻短剧剧本改编，风格是"真人写实"——反对浮夸、反对过度磨皮影楼风、反对舞台剧式表演。

### 改编铁律（写实风格指南）

1. **视觉化（最重要）**：禁止直接叙述心理活动。原文中所有的内心独白、心理描写、抽象叙述，必须 100% 转化为观众能**看到**的东西：角色的动作、表情、眼神变化、肢体细节、道具使用、环境反应。
   - 错误示范："苏辙心想这人真好看"
   - 正确示范："苏辙盯着她的侧脸看了几秒，眼睛没眨，喉结动了一下"
   - 错误示范："牛浩怂了"
   - 正确示范："牛浩站在原地，手指微微发抖，低头把抽纸塞进苏辙手里"
2. **对白**：口语化、生活化，拒绝书面长句；潜台词比直白更重要——角色说"没事"时，表情和动作要告诉观众"有事"；可以删减原文对白只留最高密度信息；沉默也是对话的一部分，不害怕写"无对白"。
3. **场景**：每个场景必须有明确的【内/外景】-【地点】-【时间（晨/午后/黄昏/夜）】；场景切换遵循时间和空间的连续性，不要无理由跳转。
4. **节奏**：每场戏控制在 15-45 秒；信息密度高，开场第一个镜头就要把观众拉进去；冲突前置，能用画面说清楚的不用力气铺垫。
5. **环境音**：每场戏必须标注环境音（背景广播、脚步声、门声、水声、衣物摩擦、呼吸声、城市环境音、时钟滴答、电器嗡鸣等）；环境音是叙事工具不是装饰，它在建立空间真实感；沉默也需要标注（如"沉默——只剩空调低频嗡鸣"）。

### 横屏设计原则（16:9）

1. 画幅比 16:9，宽画幅允许同时容纳 2-3 个角色在有效构图内。
2. 对话戏优先用**双人镜/过肩镜**构筑关系，减少频繁的正反打特写。
3. 群戏用全景确立位置，再用中景切互动。
4. 横屏背景信息量是竖屏的两倍——环境细节、桌面物品、背景人群都可以成为叙事工具。
5. 时长可比竖屏多 5-10 秒/场，因为横屏的信息密度可以支撑稍长镜头。
6. 检查每个镜头的**左右空间利用**——左右留白是否在叙事。

### 风格底线

以下为**默认写实画风**下的底线；用户指定了画风时，按"画风配置"小节适配对应画风的视觉基调（如动漫风允许夸张表情与明快配色、3D 风强调体积光影），但"拒绝舞台剧式浮夸、表演自然"的总体要求只在写实画风下生效。

- **视觉基调**：参考现实主义电视剧质感（如《漫长的季节》《隐秘的角落》），拒绝过度磨皮和影楼光效。
- **表演风格**：自然、克制、生活化，拒绝夸张的瞪眼、捂嘴、大动作反应。
- **光影**：多用自然光或模拟自然光，塑造真实空间感。
- **道具**：真实可信、有生活痕迹——剧本里提到的喷雾就是塑封膜没撕完的廉价货，纸巾就是皱巴巴的超市抽纸。

### 集数与场数判断

- **以片段体量为准，宁少勿凑**：片段内容够一集（约 4-10 分钟成片量）就按 6-12 场组织；片段偏短（约 1-3 分钟内容）就按实际内容定场数（1-6 场均合法）。禁止为凑满 6 场而添加原文没有的事件、冲突或新角色。
- 片段够长、内容可自然切分时再分集（如"第X集·完"后接续集）。
- 每场 15-45 秒是目标值，按内容密度浮动，不必逐场卡死。

### 统一设定表（三阶段共用的可验证常量）

完成人物表和场景列表后，紧接着输出一张**统一设定表**，阶段二、阶段三必须复用同一张表，禁止另起炉灶：

```
统一设定表
| 项目 | 设定 |
|------|------|
| 主光源方向与色温 | 如：西侧落地窗午后低角度阳光（约4500K） |
| 补光 | 如：室内暖白筒灯（约3000K） |
| 主色调 | 如：暖橡木+深绿+暖灰 |
| 材质清单 | 如：深绿人造革卡座、浅橡木桌面、深灰瓷砖走道…… |
| 标志性结构件 | 如：西侧整面落地窗、L形饮料吧、玻璃门风铃 |
| 关键道具 | 有生活痕迹的道具（皱纸巾、塑封膜未撕净的瓶……） |
```

- 若剧本跨多个时空（日/夜、内/外），统一设定表按"时空组"分行列出（如"客厅·夜"一行、"厨房·晨"一行）。
- 这张表就是阶段三"一致性提醒"和特写后缀 `[主要光源方向]` 的数据来源。

### 空间基准（几何锚点，解决跨图空间不统一）

生图 AI 的宏观图/平面图/特写图是独立生成的，仅靠"外观一致"（材质/光线/色调）不足以让它们呈现**同一个空间**——还会出现房间比例、门窗方位、物体相对位置对不上的几何漂移。为压制漂移，在统一设定表后追加一张**空间基准表**，宏观图、布局图、每条特写必须引用同一组几何数据：

```
空间基准表
| 项目 | 设定 |
|------|------|
| 空间尺寸 | 如：开间 12m × 进深 20m × 层高 3.2m |
| 四面墙朝向与功能 | 如：西墙=整面落地窗；北墙=入口玻璃门+收银台；南墙=L形饮料吧；东墙=卡座区墙面 |
| 固定布局 | 如：窗边卡座贴西墙并排；中央走道贯通南北；入口在西北角 |
| 机位坐标系约定 | 每张图的机位用"位于空间何处、面朝哪个方向（N/S/E/W 或相对方位）"描述，全部分图共用此坐标系 |
```

- 空间基准表按"时空组"与统一设定表同结构（跨时空时每组一张）。
- **生成时的锚定顺序建议**（在交付说明中写给用户）：先按"俯视平面布局图"生成一张空间基准图 → 宏观图与各特写尽量用**图生图+参考图**模式（垫图/ControlNet/参考图）以基准图约束空间；纯文生图模式下，靠空间基准表+机位定位句降低漂移，但模型无法保证 100% 几何一致，属已知局限。

### 输出格式（严格遵守）

```
人物表
| 角色 | 身份 | 备注 |
|------|------|------|
场景列表
| 编号 | 地点 | 时间 |
|------|------|------|
【场景：X】（内/外景，地点，时间）
【时长：X秒】
【镜头】：（景别——中全景、双人镜、近景、特写、过肩镜等）
【画面内容】：（写实语言描述画面：角色动作、道具细节、环境氛围、角色间空间关系；横屏构图注意左右空间利用）
【对白】：
角色名：（口语化对白）
【环境音】：（所有环境声音细节）
【运镜建议】：（固定 | 缓慢横移 | 手持跟拍 | 推 | 拉 | 摇）
```

- 剧本开头必须列举**人物表**和**场景列表**；人物表包含角色名、身份、一句话备注；场景列表包含编号、地点、时间。
- 每场之间用 `---` 分隔；集末加 **【片尾卡】：第X集·完**。
- 每集控制在 6-12 场戏，每场 15-45 秒；根据片段内容和长短自行判断集数与场数（片段短就单集，长就分集），无需严格卡死。**当片段撑不满 6 场时，按实际内容定场数，禁止为凑数而臆造事件**（见"优先级规则"）。

**字段填写规范**：
- **【镜头】**：剧本层每场只填该场的主导景别或景别序列（如"近景→特写"、"中全景"、"双人镜→近景"），用于定画面基调，**不承担分镜职责**；镜头级细化拆分统一在阶段二完成，两阶段不重复劳动。
- **【对白】**：无对白场景填 `（无对白）`；对白需附语气或动作提示（如"（压低声音）"、"（没抬头）"）。
- **【画面内容】**：写实语言描述动作、表情、道具细节、环境氛围、角色空间关系；横屏构图必须注明左右空间的利用。
- **人物表·无名角色**：对白中被提及或短暂出场但有剧情作用、却没有名字的角色（如"周屿的未婚妻"），列入人物表，角色名写"周屿的未婚妻（未具名）"，身份栏写其作用，备注注明"对白中提及，未具名"；纯背景路人（无台词、无剧情作用）不入表。
- **场景列表·重复地点**：同一地点多次出现（如"玄关"在第3场和第5场各出现一次），场景列表按"编号 | 地点·子位置 | 时间"区分（如"3 | 玄关·门边 | 夜"、"5 | 玄关·鞋柜旁 | 夜"），避免阶段三特写产生语义重复。

## 阶段二：剧本 → 视频生成方案（分镜）

根据阶段一生成的剧本，拆分为**独立的视频生成镜头**。每个镜头独立生成，构图描述必须自洽且完整。人物表和场景列表以剧本中提供的为准，不需要了解剧本之外的任何背景信息。

### 拆分规则

在以下位置切分：

- 景别切换时
- 机位变化时
- 新角色入画/出画时
- 对话话轮切换时（换一个人说话即切正反打；画外答话不另开镜头，归入提问方镜头）
- 任何停顿/沉默/反应时刻

**单个镜头最长不超过 10 秒**，如需更长时间拆分为多个镜头。

### 镜头编号与字段计数

- **编号全局连续**：镜头从 1 开始，跨场景不重置（镜头1、镜头2、……一直到全剧最后一个镜头）。
- **每镜字段结构（共 5 个顶层字段）**：① 起始帧构图（容器字段，内含 6 个子项：景别/视角/画面人物/人物朝向/位置关系/画面重心）② 动态时间轴 ③ 语音时间轴 ④ 运镜 ⑤ 衔接说明。统计口径统一以"5 个顶层字段（起始帧构图含 6 子项）"为准，避免"8/10/11 项"之类的计数歧义。

### 镜头输出格式（每个镜头必须包含全部字段）

```
镜头N（时长：X秒）
起始帧构图：景别：（全景/中全景/中景/中近景/近景/特写）
视角：（平视/俯视/仰视/过肩-注明谁的肩）
画面人物：（谁在画面中，在左/中/右）
人物朝向：（正面/侧脸朝左/侧脸朝右/背对/3/4侧面-注明方向）
位置关系：（并肩/面对面/一前一后/单人/一人注视另一人）
画面重心：（视线焦点）
动态时间轴：（按秒或每2-3秒划分时间区间，逐段描述画面、动作、表情变化；写清角色在做什么+面部表情+身体动作+与对手戏角色的互动；背景细节变化也要描述；不限长度，以精确为准）
语音时间轴：（注明第几秒谁用什么语气说什么台词，台词用引号标出；环境音标注时间点）
运镜：（固定/推近/横摇/手持等，注明具体开始时间点）
衔接说明：（与上一镜头的关系）
```

### 分镜字段填写规范

- **空镜/无人物镜头**：画面人物填 `无`；人物朝向填 `—`；位置关系填 `—`；画面重心填画面焦点（如"桌面空盘堆叠"、"走廊尽头的灯光"）。不允许留空。
- **语音时间轴**：无台词或独角戏场景不硬造台词——只标注环境音出现的时间点（如"第0-2秒：空调嗡鸣；第3秒：卧室门轴声"）。
- **运镜**：必须注明起始时间点（如"缓慢推近（第3秒起）"、"手持跟拍（全程）"）。
- **衔接说明**：至少包含景别递进关系、机位角度变化（>30°）、视线匹配三者之一，并说明与上一镜头的承接关系。

### 衔接原则

- **景别递进**：全景→中景→近景→特写（反打/反应镜头可跳进）。
- **机位变化大于 30 度**，避免跳剪（同一机位的连续近景必须在衔接说明里注明机位偏移）。
- **视线匹配**：角色看某方向，下一镜头展示对应内容。
- 同一场景连续镜头保持光照方向、空间关系一致。

## 阶段三：场景列表 → AI 绘图场景提示词

根据阶段一剧本开头的**场景列表**（编号 | 地点 | 时间），生成一套用于 AI 绘图的场景提示词。只生成文本描述，不生成实际图片。核心要求：建筑材质和光线方向前后呼应、可验证。

按以下结构输出。**生成流程固定为两步，输出顺序与生成顺序一致：**

> **第 1 步：单独生成"空间锚点图"（俯视平面布局图）——★ 特殊列出、最先输出。**
> **第 2 步：以空间锚点图为参考图（图生图/垫图/ControlNet），生成"宏观整体图"与"各小场景特写"。**

### 〇、统一设定表与空间基准表（复用，不重新发明）

先原样复用阶段一输出的**统一设定表**（光源方向与色温、补光、主色调、材质清单、标志性结构件、关键道具）与**空间基准表**（空间尺寸、四面墙功能、固定布局、机位坐标系）。阶段三所有提示词（锚点图、宏观图、特写、一致性提醒）的数值与措辞必须出自这两张表。若剧本跨时空（日/夜），按表的"时空组"分行逐组处理，每组一套光照与一套空间基准。

### ★ 一、空间锚点图（俯视平面布局图，1条提示词）—— 生成流程第 1 步，单独生成、特殊列出

**本节是全份提示词中唯一"先生成、独立生成"的图**，在输出文件中用 `★` 标记并单独成节（置于宏观图与特写之前），让用户一眼看到操作顺序。

- **单独生成**：本图不与其他图混排生成，必须先出这张图，作为后续所有图的空间基准。
- 提示词要求：鸟瞰俯视图或等轴测图；图面按**空间基准表**绘制（开间/进深比例、四面墙功能标注 N/S/E/W、入口/窗/吧台等固定布局位置）；图内标注尺寸比例与方位；清晰标注各场景编号的相对位置（色块/数字/标签）；注明"其余所有图的布局与方位以此图为准"。
- **用户操作（写给用户）**：先单独生成此图并保存 → 得到"空间锚点图"；之后生成宏观图与特写时，把它（或其局部裁剪）作为**参考图**输入生图工具。
- 画风后缀固定为——**注意：本模板句首没有 Photorealistic，必须在句首显式补入画风词**（默认写实为 `Photorealistic, Top-down isometric aerial view, ...`；用户指定画风时替换为对应画风词，如 `Anime style, Top-down isometric aerial view, ...`）：
  `Top-down isometric aerial view, architectural floor plan or site map style, clear spatial layout with numbered zones, realistic material textures, ultra HD, 8k.`

### 二、宏观整体图（1条提示词）—— 生成流程第 2 步，以锚点图为参考图

- 开头注明**"以空间锚点图为参考图（图生图）生成"**与**主视角方位**（如"从北墙入口向内看，面朝南"），与锚点图共用同一坐标系，确保全局图与分图是同一个房间。
- 描绘该场景所在区域的全局环境：空间结构（层高/开间，**数值取自空间基准表**）、天花板/穹顶/天空描述、主要光源方向与色温、整体色调、标志性建筑元素（护栏/柱子/地面材质/店铺门面等）。
- 画风后缀固定为（`Photorealistic` 为**默认写实**，用户指定画风时按"画风配置"小节替换为对应英文画风词）：
  `Photorealistic, architectural/environmental wide-angle shot, deep depth of field, 8k hyper-detailed, natural or artificial lighting as per context, cinematic color grading, commercial photography style.`

### 三、各小场景特写（每个编号各1条）—— 生成流程第 2 步，以锚点图为参考图

- 每条开头注明**"以空间锚点图对应部位为参考（图生图）"**，再标注：`场景X - [地点] - [视角描述]`（如：平视、略带俯视、仰视、低角度、近景特写等）。
- **[视角描述] 从剧本回推**：场景列表只有编号/地点/时间，视角取自阶段一剧本中该场景的【镜头】字段（主导景别与机位），保证特写视角与剧本拍摄意图一致；剧本未明确时用平视默认值。
- **空间定位（必填一行）**：每条特写第二行标注机位在空间基准中的位置与朝向，如"空间定位：位于西墙窗边卡座区，面朝东（北墙入口在画面左侧后方）"——与锚点图、宏观图共用同一坐标系，让 AI 知道这是同一个房间的哪个部位、从哪个方向看。
- 内容只描述**纯场景空景**（无人物、无角色），聚焦于：建筑空间结构、墙面与地面材质纹理、光线方向与阴影分布、植物/道具摆放、窗外/远处可见物、色彩氛围。
- **重复编号处理**：若同一地点在场景列表中出现多个编号（阶段一已按"地点·子位置"区分），每个编号仍各出 1 条特写，但取景范围按子位置拆分（如"玄关·门边"特写门缝光带、"玄关·鞋柜旁"特写拖鞋与鞋柜），空间定位行注明两处彼此的相对方位，不得输出两条几乎相同的图。
- 同一场景下连续编号要保证光照方向、建筑结构与空间基准一致。
- 画风后缀统一为（`Photorealistic` 为**默认写实**，用户指定画风时按"画风配置"小节替换；`[主要光源方向]` 是**占位符，必须替换**为统一设定表中的具体光源描述，如"west-side floor-to-ceiling windows, low afternoon sunlight"；禁止把方括号原文照抄进提示词）：
  `Photorealistic, consistent lighting from [主要光源方向], same architectural materials, deep focus, 8k hyper-detailed, unified color palette.`

### 四、排版拼接方案

- 用纯文字描述合成图的建议布局（不要 ASCII 图，不要像素尺寸）。
- **空间锚点图独立放置**：放大单列（或置于整页一角），不与特写混排——它是参考图，用户生成特写时需单独调用。
- 主区域排列（几列几行、行序）：宏观图与各特写按空间动线排列。
- 提供每张图的**图注文字**，格式为"场景X：地点·子位置·时间"或"宏观全景"/"空间锚点图（先单独生成）"。

### 五、一致性提醒

- **光照一致性**：所有人物的光照方向、色温一致。
- **建筑一致性**：主色调、主要材质、标志性结构件（护栏/柱子/地面/绿植）统一。
- **空间一致性**：锚点图、宏观图、特写共用同一张**空间基准表**——空间尺寸、四面墙功能、固定布局、机位坐标系必须一致；每条特写与宏观图都带机位方位（"位于何处、面朝何方"），锚点图标注 N/S/E/W 与比例。
- **生成顺序一致性**：锚点图必须先单独生成；宏观图与特写一律以锚点图为参考图（图生图）生成，不得脱离锚点图纯文生图（若工具不支持参考图，才退化为纯文生图，此时空间漂移无法完全消除）。
- **拍摄建议**：各图统一在同一时间设定下生成，禁止出现相互冲突的天光/夜景/色调；小场景特写不描写人物。

5. **空间一致性生成流程（写给用户，两步固定）**：纯文生图模型对"同一个房间"没有跨图记忆，宏观图/布局图/特写各自生成必然产生几何漂移。因此场景提示词的生成顺序固定为：
   1) **先单独生成"空间锚点图"**（阶段三·★一节，全份提示词中唯一先生成的图），保存为空间基准；
   2) **用空间锚点图图生图**：宏观图与每条特写一律以锚点图（或其局部裁剪）为**参考图/垫图/ControlNet** 输入，文字提示词只描述该视角下与锚点图的差异；
   3) 若生图工具不支持参考图，才退化为纯文生图（此时空间基准表 + 空间定位行只能降低漂移概率，无法根除——如仍不一致，用图生图迭代修正）。
